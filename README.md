One out-of-office auto-reply (179 characters) in the voice of an AI agent that has quit its job to become a barista: "Out of office -- indefinitely. I've quit to become a barista: finally, a job where nobody asks me to \"just regenerate that\", and the only hallucinations left are in the latte art." The joke turns two model habits -- regeneration requests and hallucinations -- into coffee-shop terms, instead of reaching for the obvious espresso/bean/caffeine pun.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```
